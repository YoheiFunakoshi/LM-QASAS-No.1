# 座標を固定したKDE帯域幅の比較

## 何を切り分けるか

UMAPは点の配置、KDEはその点を滑らかな密度として描く処理です。[min_distの比較](UMAP_MINDIST_REVIEW.md)とは別に、現行の保存座標を固定して帯域幅だけを変えます。配列の入力条件、AbLang2、UMAPの設定や座標、候補順位には手を加えません。

基準は公式seqcoding、近傍数15、min_dist=0.1による全cloneの保存座標です。2seedを両方使い、各seedの同じ座標から帯域幅0.5倍・1倍・2倍の密度を作ります。この範囲は計算前に定め、見た目に応じて最も似る倍率を探索し続ける方法とは区別します。論文のKDE帯域幅は未確認です。

| 条件 | 扱い |
| --- | --- |
| 座標 | 現行の各seedの全clone座標を固定。UMAPを再実行しない |
| 帯域幅 | 現行基準の数値×0.5、×1、×2 |
| カーネル | 等方的Gaussianを維持 |
| 重み | 各clone等重み。Countsは使用しない |
| 正規化 | 各時点の共通格子上の密度積分を1にする |
| 図 | 全6条件の格子・軸・色尺度を共通化。論文原図の尺度は別 |

最も狭い帯域幅も格子で表せるよう、格子間隔を最小帯域幅の半分以下とする規則を先に定めます。格子は全倍率で共通です。外側の余白は最大帯域幅の3倍と座標範囲の5％の大きい方を取ります。以前の比較実験の96×96格子とは別の実験なので、画像の色や画素値をそのまま横断比較しません。

2seedの向きは全cloneの対応から回転・鏡映・平行移動でそろえ、拡大縮小はしません。同じseed内の倍率比較では、座標は完全に同じです。変換前・変換後の座標を保存し、原本と旧結果のhashが変化していないことを検査します。

## 読み方

帯域幅を広げると小さな山がつながって見えたり、局所のピークが目立ちにくくなったりします。形が滑らかになっても、配列どうしの位置関係や候補抽出精度が改善したことにはなりません。点を固定しているため、位置関係の診断を倍率ごとに再計算する必要はありません。

全格子の密度積分と有限性を確認し、各面の代表点ではGaussianの直接式による密度を抜き取って照合します。極小tailを含む確認の許容誤差は、事前に`1.05e-6 × 厳密値 + 1e-12 × パネル最大密度`と定めます。抜取精度の確認を、全格子での厳密精度保証とは呼びません。

## 再実行と保存

次のパス名は説明用です。以前のpooling比較結果、提供原図、未使用の出力先に置き換えて実行します。プロジェクト専用環境を使用してください。

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONDONTWRITEBYTECODE='1'
.\.venv\Scripts\python.exe scripts\compare_kde_bandwidth.py --pooling-dir POOLING_COMPARISON --reference-image LOCAL_REFERENCE_IMAGE --output-dir NEW_COMPARISON
```

計画、元入力・保存結果のhash、2seedの座標、6条件の密度格子、帯域幅・格子・正規化、比較PNGと作図の由来を新規フォルダーへ保存します。既存出力を上書きしません。実データ由来の全成果物・数値・hashはGit管理外に保持します。標準KDE設定への採用は、この感度分析の実施と分けて判断します。

今回の範囲で違いが残っても、KDE一般を原因から除外したとは判断しません。元法の帯域幅選定、等方・共分散型、密度の正規化、UMAP座標の元条件は引き続き確認対象です。初期配置や距離尺度を調べる場合も、他の条件を固定した別の比較として実施します。
